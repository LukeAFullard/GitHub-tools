Private by design

Runs in your browser

There is no GitDoco server. Your browser talks to GitHub directly, and nothing is uploaded anywhere else.

Token stays in memory

Your GitHub token is only sent to GitHub, never saved, and gone when you close the tab.

Secrets hidden

API keys, tokens, private keys and .env files are detected and replaced before you copy anything.

Clear about the rest

The Dependencies tool sends package names and versions to deps.dev to look up licenses. Nothing else leaves your browser.

Repository content is untrusted input to your AI: code, issues and comments can contain text written to steer it. Review the output before using it for sensitive work.

Questions

Is GitDoco free?

Yes. It is free, with no account and no usage limits beyond GitHub's own API limits, and its source code is on GitHub.

Do I need a GitHub token?

Not for public repositories. Without a token GitHub allows 60 requests an hour, which covers most small and medium repos. A token raises that to 5,000 and is needed for private repos. For Discussions, a token also switches to GitHub's official API.

Which AI tools does it work with?

Any that accept text. Presets for Claude, ChatGPT and Gemini set the output format and token budget; Custom lets you choose Claude XML, Markdown, generic XML or JSON and your own split size.

What if the repo is too big?

Deselect folders, minify code, or split the output into parts that each fit your AI's context window. The token meter shows where you stand before you copy.

Can I use it on a private repo without giving it a token?

Yes: download the repo as a .zip and open it in the Code or Dependencies tool. The archive is read in your browser and never uploaded.

Is the license report legal advice?

No. It groups licenses to show what deserves a closer look, and leaves the conclusions to you (or your lawyer).
